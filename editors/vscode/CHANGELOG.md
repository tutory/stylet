# Changelog

The extension is released together with stylet; see the
[GitHub releases](https://github.com/tutory/stylet/releases) for the changes in each version.

## 0.1.0

- Highlighting, diagnostics as you type, formatting with the project's `stylet.toml`
- Completions: CSS properties and keywords, custom properties, placeholders, custom media
- Go to definition and references for placeholders, custom properties and custom media;
  go to definition for `@import` paths
- Outline of rules and placeholders
- Bundles the stylet binary; a workspace's `@tutory_de/stylet` package takes precedence
